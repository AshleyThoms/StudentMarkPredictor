# 🎓 Student Mark Predictor 

A simple Machine Learning web app that predicts student marks based on the number of study hours.

This project was built as part of my AI & ML learning journey after completing an AI/ML bootcamp. The goal of this project is to understand the basics of regression models, data processing, and deploying ML applications with Streamlit.

---

## 🚀 Demo 

Live App: https://studentmarkpredictor-ashley.streamlit.app

---

## 📌 Features 

- Predict student marks based on study hours
- Simple and interactive Streamlit interface
- Machine Learning model using Linear Regression
- Beginner-friendly project structure
- Web deployment using Streamlit Cloud

---

## 🛠️ Tech Stack 

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
